# Loomis 头部构造：球体、面部平面与下颌

默认显示按用户指定比例建立的面部平面模型，保留原来的 yaw / pitch / roll 定义。直接旋转观察，或关闭“显示面部拼接平面”回到球体练习。球壳、额面、正面、颧侧面、口鼻面、下颌和简化鼻楔都有独立转折，GPU 按真实前后关系遮挡。

## 面部怎么画

1. 画球、定脸中线和眉骨赤道。侧圆半径取 `2R/3`，所以切面位置是 `√(R² − (2R/3)²) = √5R/3 ≈ 0.745R`，不是 `√5R/2`。
2. 沿头部自己的 Y 方向定位：发际 `+2R/3`，眉骨 `0`，下眼睑 `−R/3`，鼻底 `−2R/3`，嘴线 `−R`，下巴 `−4R/3`。旋转后这些方向随头转动，不是沿屏幕竖直量。
3. 先接出较窄的正面，再从左右转折边向耳侧接斜面；额头与口鼻面也用不同倾角的平面连接。面部中线沿这些平面连续折转。
4. 耳朵从侧圆底部向上 `2R/3`；标准侧圆下，耳下缘为鼻底、耳上缘为眉骨。耳下缘连接下颌角，再收向下巴。侧圆尺寸改变时，耳朵仍从新的侧圆底部向上量。
5. 下巴宽度和面部前伸量可调。开关“简化鼻楔”可单独观察鼻子的体块；“比例线与文字”“背面虚线”“叠加球面十字线”用来逐层核对。默认关闭背面虚线以便临摹。

这些是用户给定的绘画比例。下眼睑、嘴线等作为定位参考，不把它们当成所有人的固定解剖比例。除用户指定的高度与侧圆外，正面宽度、颧侧面角度和鼻楔厚度为此程序的示范构造，可继续调整。

面部由半空间 `n·p ≤ d` 的交集形成，面与面相交就是直边。Y 各高度截面给出彩色比例线；投影与旋转仍使用下文同一组短公式。转头只更新旋转矩阵，不重建面部。

独立 Godot 4 小程序。双击 `start.cmd`（自动寻找 PATH 或 Downloads 中的 Godot），也可用 Godot 导入此目录的 `project.godot` 后按 F5。项目原有主入口仍是小队竞技场。

## 怎么练

1. 点“正面”，单独拖 Yaw，观察蓝色中线从直线变成弧线。
2. 单独拖 Pitch，观察红色横线如何弯曲；正值低头，负值仰头。
3. 拖 Roll，观察整个十字线与切面一起倾斜。
4. 打开“两侧削平”，拖切面位置，观察切口与薄片。薄片留在球上原位，默认不透明度 22%；可调得更透明，透过它看清平切面。薄片是球冠，切口是平面圆。
5. 关掉背面虚线，自己临摹；再打开虚线和经纬网核对。
6. 紫色耳侧经线位于 Z=0 平面，与蓝色面部中线的 X=0 平面垂直。它沿球面走圆弧，左右切面上接直线，形成连续的闭合构造线；“耳侧经线”开关可单独隐藏它。
7. 红色赤道/横线也在左右切面上接直线。调整高度 h 后仍成立；高度太高、横线没有碰到切面时，保持完整圆弧。辅助纬线采用相同规则。

滑条值表示同一个绝对姿态，操作先后不影响结果。正值以人物自己的右侧为准：正面看时向画面左侧。左右耳都切，切面中心位于头部局部 X 轴。半透明球冠不挡住保留头壳的构造线。

## 最短公式

半径取 1，X 朝左耳，Y 朝头顶，Z 朝脸前。参数 t 绕一圈：

```text
竖线   p = (0, sin t, cos t)
横线   p = (clamp(r sin t, −a, a), h, r cos t)   r = √(1 − h²)
切口   p = (±a, ρ sin t, ρ cos t)     ρ = √(1 − a²)
耳侧线 p = (clamp(sin t, −a, a), cos t, 0)

旋转   q = Ry(−yaw) Rx(pitch) Rz(roll) p
投影   (u,v) = (u₀,v₀) + s(qx,−qy)
```

R 为标准右手旋转矩阵。右边先计算：固定姿态的矩阵计算顺序为 roll → pitch → yaw；等价于依次绕局部 Y（负 yaw）、局部 X（pitch）、局部 Z（roll）转动。Godot 的 `Vector3.BACK` 是 +Z，此程序把它用作脸前方。

耳侧线的 `clamp` 只把超出 ±a 的 X 坐标夹到切面上，因此圆弧在 `(±a, ±ρ, 0)` 处连续接上切面直径。旋转后，这部分仍然是直线。关闭削平则恢复完整大圆。

横线同样夹住 X 坐标，在 `(±a, h, ±√(1−h²−a²))` 处接上切面弦段。赤道 h=0 时经过切面中心；其它高度时弦段随之偏移。如果 `√(1−h²) ≤ a`，没有与切面相交，也就不需要直线段。

**弧度来自圆的投影。** 球面十字线是圆弧，斜着看投影成椭圆弧。正面且 h=0 时，两条圆都侧对视线，于是投影退化为直线。横线移到 h≠0 仍然是圆；正面时会成为不同高度、不同宽度的直线。

只转 yaw=ψ 时，中线的纸上坐标（去掉中心与比例）尤其简单：

```text
u = −sin ψ · cos t
v = −sin t
```

所以椭圆竖半轴为 1、横半轴为 |sin ψ|。不需要凭感觉猜弯曲多少。

任意圆在正交投影下：长半轴=圆半径，短半轴=圆半径×|n·k|。n 为转好后的圆平面单位法向量，k=(0,0,1) 为朝观察者方向。切口因此是长半轴 ρ、短半轴 ρ×|(R·X)z| 的椭圆。

采用正交投影，适合学习圆弧、切面和面部体块；不包含透视缩短随距离变化的效果。关闭面部显示后仍可单独研究原有球壳。

## 验证

```powershell
Godot --headless --path demos/head_study --script res://validate.gd
Godot --path demos/head_study -- --capture
Godot --path demos/head_study --script res://benchmark.gd --disable-vsync
Godot --path demos/head_study --script res://validate_render.gd
Godot --headless --path demos/head_study --script res://validate_loomis.gd
Godot --path demos/head_study --script res://benchmark.gd --disable-vsync -- --rotation-only --no-grid
```

第一条检查正负方向、实际滑条更新、140 个旋转组合、圆在球面和切面上、投影及遮挡。第二条实际渲染正面、组合姿态、背面四张截图（`preview_*.png`，不纳入版本管理）。第三条开启全部经纬网，连续改变所有角度、切片位置与透明度，统计 120 个真实渲染帧（先预热 20 帧）。

第四条实际渲染并检查像素，验证原位球冠、不透明度变化、整球开关与背景透明。

第五条检查 27 组切面/下巴宽度/面部前伸参数下的闭合面部、鼻楔、精确高度截面、遮挡与转头时不重建几何；渲染检查也覆盖下巴确实超出原球壳、面部开关以及额面不被球体穿透。最后一条测默认无经纬网、只连续旋转的交互速度。

填色由单个 GPU 着色器直接求球体及面部半空间交点，不在 CPU 上重建、排序上万个三角形。RTX 3070 Laptop / Godot 4.6.2 上，新增面部默认显示下连续旋转的中位帧耗时约 9ms，95% 帧不超过 12ms；开启全部辅助网格并改变切面约 20ms（不同设备会变化）。静止时不重新计算构造线，转头不重建面部顶点。
