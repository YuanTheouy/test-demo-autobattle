# AutoBattle — 即时小队竞技场

当前分支 `realtime-arena`，参考用户提供的自动宠物对战视频，重点借鉴连续走位和圆环落点读秒。当前为 **2v2 全自动即时战斗**，保留四主动/四反应技能与条件编辑。没有格子移动或格子命中规则；内部导航采样只辅助寻路，角色可以停在任意合法位置。

## 试玩

双击 `启动游戏.command`，空格开始/暂停，R 重开，N 前进0.2秒。默认1×实时播放，可切0.5×/2×；固定1/60模拟步长不随播放速度变化。

- 蓝方攻击：蓝紫色；红方攻击：橙红色。棋子本体仍为红蓝。
- 移动：绿色路径、方向箭头与目的地圆点；关闭技能范围也保留移动提示。
- 默认炮击压制 vs 突击游击，可独立切换七种队伍预设。
- 点击角色，可配置其四个主动、四个反应槽和两个条件；修改后重开。配置暂不跨启动保存。

## 圆环技能时序

抛射轰击改为 **单个半径64像素的圆形落点**，不再是三处散布，且不追踪移动目标。

1. 开始准备时锁定落点，显示完整的淡色伤害边界。
2. 准备0.25秒，圆环从顶部开始补完。
3. 抛射飞行0.65秒，圆环沿用同一个累计进度，不重置。
4. 总计0.9秒，圆环补满时爆炸，圈内身体重叠者受到1点伤害。
5. 满环爆炸反馈持续0.3秒，特效不造成重复伤害。

计时环与伤害圈使用同一半径；从上方覆盖圆形区域，不被墙阻挡。护盾、防御依然有效，无友伤。落点固定，提前走出半径（包含身体半径）可以躲避。其他技能仍有实弹、扇形霰弹、锁向蓄力光束等不同出招方式。

## 战斗节奏

- 普通射击/霰弹/炮击收招0.3秒，重射/岩弹0.6秒；之后武器恢复0.55秒。
- 霰弹准备0.25秒，落岩0.35秒；风系两发间隔0.22秒。长激光仍蓄力1.1秒、收招0.8秒。
- 武器恢复时，基础行为做最多32像素的小幅侧移，面朝敌人，保持射程与视线；无安全位置则守住射位。
- 侧移没有无敌帧，逐帧让位于玩家AP、PP与真正的威胁规避。技能冷却、伤害和生命值不变。

## 小队配置

每个角色4HP，技能/治疗/护盾均为小整数。相同属性与技能池，玩家通过条件优先级改变打法；无AP/PP点数。

- 玩家主动从上至下选择第一条可用规则，基础攻击/接敌/搜寻最后兜底。
- 战场事件触发相关反应，玩家PP先于基础步行避险。
- 规避按真实攻击形状、剩余时间和可达位置选择；已开始的吟唱、射击、收招不能免费取消。
- 底层不再自动等待收招反打；可由玩家配置“敌人正在收招”的攻击规则。
- 队友目标偏好、标记接强射、命中后协同追击、给队友护盾与治疗等配合继续保留。

此版保留原型的硬边界与18–42秒连续缩圈、60秒超时平局。界面距离改以米为单位（1米=80像素），只是长度标尺，不约束位置。

**暂不实现**召唤师部署、手动瞄准关键技能、3v3或宠物美术；先验证2v2的可读性和战术配置。

## 验证

```sh
Godot --headless --path . -- --arena-test
```

验证连续移动、单个固定落点、准备到飞行的进度连续、结算时间与实际半径、玩家PP优先，再跑炮击队对七预设并交换出生侧的14场对局。报告：`reports/arena-validation.json`。

节奏专项：`--tempo-test`，检查冷却走位、朝向、技能接管、掩体边缘、快招与长蓄力。

补充回归：`--content-test`（18场及空槽/支援/速度一致）、`--pattern-test`（14场）、`--evasion-test`、`--blast-test`、`--movement-test`。旧格子测试入口不适用于此分支。功能通过不代表平衡已经成立。

双击 `加速统计.command` 运行本版专项及14场对局。

## 版本切换

保存当前改动后：

```sh
git switch grid-tactics   # 整格移动实验
git switch main           # 最初连续移动存档
git switch realtime-arena # 本版：参考视频的即时竞技场
```

`main` 与 `grid-tactics` 原版本未覆盖；本地仓库尚未配置远程。当前入口是 `scripts/battle.gd`，`scripts/grid_battle.gd` 是旧格子实现文件，本分支不使用它。
