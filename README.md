# AutoBattle — 格子战术实验

当前分支：`grid-tactics`。本版是 **实时自动战斗 + 离散棋盘**，尚未改成双方轮流操作的回合制。

## 启动

双击 `启动游戏.command`；空格开始/暂停，R 同配置重开，N 步进0.2秒。支持0.5/1/2倍速，所有速度共享1/60秒固定模拟步长。

## 棋盘与移动

- 固定8×8方格，四方向移动，每次一格。不斜走、不叠格、不迎面穿过。
- 每个角色4HP，伤害、护盾、治疗均为整数。
- 移动耗时0.55秒；短冲刺、侧闪0.25秒。目标格预占，别人不能抢入。
- 逻辑位置始终是格心：移动期间占起点，到达后切换到终点；中间插值仅是动画，不是可停靠位置。起点淡色标记占格，虚线显示移动方向。
- 地形占整格。此版本取消连续缩圈，60秒未分胜负则平局。
- 开战前可把蓝方拖动到己方两列内的空格，自动吸附格心。

## 攻击与范围

距离按曼哈顿距离计算（横纵步数相加），射程3格。点击角色，显示通用可选目标范围；蓄力和弹道期间显示实际锁定命中格，可关闭范围显示。

| 技能形态 | 预告和命中格 | 出招 |
|---|---|---|
| 普通射击、标记、强射、火矢、落岩等 | 锁定目标所在的一格 | 前摇后发射；目标离开该格即可躲过 |
| 风刃、追风 | 同一个锁定格 | 两次命中判定，各1伤害，间隔0.35秒 |
| 蓄能贯穿 | 横向或纵向连续3格，遇墙停止 | 蓄力1.1秒，瞬发2真伤；穿人不穿墙 |
| 霰弹 | 前方第一排1格、第二排3格，墙后格不计入 | 准备0.55秒，每格1伤害 |
| 抛射轰击 | 中心及上下左右十字五格，墙格/棋盘外不计入 | 准备0.65秒、飞行0.8秒，每格1伤害 |

显示与结算使用同一组格子，身体大小不再决定擦边命中。地形遮挡起手视线，抛射落点确定后不追踪；十字范围可以覆盖墙另一边的地面。不伤队友。其他技能的当前参数可悬停菜单查看。

## AP、PP 和基础行为

四主动、四反应槽保留。选取第一条满足条件且可执行的规则，玩家槽优先于基础槽。

- AP：开战/一格移动完成/技能收招结束后，从第一条重新选择。没有可用玩家AP，基础攻击 → 接敌/调整射位 → 搜寻。
- PP：威胁覆盖自己或队友所在格、队友命中、受伤等事件条件成立时检查。玩家PP优先，最后才尝试基础移向相邻安全格。
- 一格移动、攻击前摇和收招期间均不可取消。到达或动作结束后，若威胁仍在，可重新响应。普通步行不保证来得及避开攻击。
- 不再由底层自动等待收招反打；可以配置“敌人正在收招”的主动规则。
- 全空槽也可搜索、接敌和战斗。基础AI只使用队伍已发现的敌人和最后位置。

## 验证

```sh
Godot --headless --path . -- --grid-test
```

专项验证四方向单步、占格与预约互斥、技能形状/命中一致、光束挡墙、玩家AP/PP优先、空槽战斗和三档播放速度一致。另跑炮击队对七预设并交换出生侧，共14场，输出 `reports/grid-validation.json`。

双击 `加速统计.command` 可重复这14场。它是功能对照，尚不能代表阵容平衡。`reports/` 其他文件属于连续移动历史版本，不应用于新版结论。

当前格子实现为 `scripts/grid_battle.gd`，复用 `battle.gd` 的规则编辑界面、基础字段与辅助函数；旧模拟和旧测试保留供对照，格子入口只使用 `--grid-test` / `--batch-test`。
