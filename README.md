# AutoBattle — 2.5D 小队竞技场

当前分支 `pseudo3d-arena`（原平面版保留在 `realtime-arena`），参考用户提供的自动宠物对战视频，重点借鉴连续走位和圆环落点读秒。当前为 **2v2 全自动即时战斗**，保留四主动/四反应技能与条件编辑。没有格子移动或格子命中规则；内部导航采样只辅助寻路，角色可以停在任意合法位置。

## 作战配置界面

- 顶部四张角色卡显示双方成员、血量、精力和动作；点击卡片或战场机甲切换编辑对象。
- AP用暖红、PP用浅蓝，规则按「优先级 / 技能 / 条件一 / 条件二 / 检查状态」排列；金色整行持续显示正在执行的规则。
- 每组四个玩家槽，下接灰色锁定基础规则；↑↓交换相邻规则，修改后重开。技能悬停显示说明，长条件可悬停查看完整文字。
- 开始、重开、步进、出生侧与播放速度移到战场下方；战斗记录默认折叠。只调整界面与优先级编辑交互，战斗数值未变。

## 试玩

胜负确定后只记录结果，不暂停模拟：剩余弹道、特效、角色移动和恢复继续。空格仍为暂停/继续，R或重开按钮才开始新局；结果不会因后续伤害重复改写。

双击 `启动游戏.command`，空格开始/暂停，R 重开，N 前进0.2秒。默认1×实时播放，可切0.5×/2×；固定1/60模拟步长不随播放速度变化。

- 蓝方攻击：蓝紫色；红方攻击：橙红色。棋子本体仍为红蓝。
- 移动：绿色路径、方向箭头与目的地圆点；关闭技能范围也保留移动提示。
- 默认风火轰鸣 vs 山林协防，可独立切换九种队伍预设。
- 点击角色，可配置其四个主动、四个反应槽和两个条件；修改后重开。配置暂不跨启动保存。

## 2.5D 演出

- 地面使用斜俯视投影，角色仍连续移动；没有格子回合，也没有改变技能判定。
- 程序绘制机甲底盘、炮塔、炮口、履带和阴影；墙体具有48像素的视觉高度，按前后关系排序，遮住身后机甲时半透明。
- 技能伤害圆、扇形、直线和绿色移动路径统一使用世界坐标投影；圆形预警在斜视图中成为椭圆，仍从同一个计时进度补满。
- 炮弹采用独立高度轨迹和地面影子；火爆带升空火团与碎屑，裂地冲击竖起岩刺，激光在炮口高度发射。风刃、岩弹、治疗、护盾、闪避残影和浮动伤害分别绘制。
- 100HP、伤害、射速、闪避CD、后坐力、敌我碰撞与反弹沿用上一版；本轮不增加技能种类，以便直接比较演出。
- 点击机甲编辑；开战前可在出生区域拖动蓝方，鼠标采用逆投影并保留抓取偏移。
- `scripts/arena_view.gd` 只负责绘制，不能修改模拟状态或消耗随机数。右侧策略编辑仍为平面UI。

验证：`--view-test` 检查投影往返、视觉高度、范围映射和拖动；`--view-preview=air|blast|laser|earth` 从真实对局中捕获对应效果到 `preview.png` 后退出。

## 策略运行可视化

- AP依次显示4个可编辑玩家槽，以及锁定的普通攻击、调整站位、接敌、搜寻；PP显示4个玩家槽和锁定的步行避险。基础避险是现有的预警步行规避，不冒充侧闪技能。
- 金色整行表示当前执行来源，覆盖前摇、发射、收招或移动阶段，直到动作结束或被另一个规则接管；不依赖原来的短暂触发闪光。
- 每行右侧显示执行阶段或上次实际扫描结果：技能CD、公共CD、精力不足、目标/事件条件不满足，或者上方已接管而未检查。显示层不重新运行AI、不改变判定。
- 基础规则不可编辑；角色下拉框或点击机甲可切换观察对象，右侧滚动查看资源详情和日志。手动大招独立，不伪装成AP/PP槽。
- `--strategy-view-test` 验证优先级记录、持续高亮、基础行为归属、PP接管、死亡和槽位数量。

## 精力与公共施法CD

- 精力上限100，开局满；普通移动/待机每秒恢复12，施法、瞄准、发射、收招和治疗保护动作期间不恢复。普通移动不消耗精力，速度在55%–100%之间随精力连续变化；侧闪保持固定距离与速度，但消耗20精力。
- 平A消耗15，小法术/治疗/保护25，大范围法术和长激光45，手动大招70；冲刺20，架枪防御10，普通绕侧/后撤不消耗。
- 技能起手扣一次精力，连发不重复扣；起手后被取消不退款。精力不足跳过这条规则，继续检查其他规则或基础移动。
- 公共CD从技能生效/最后一发开始，与收招并行计时：平A1.8秒，小法术2.3秒，大法术3秒，大招4秒。收招结束不会重新设置公共CD。
- 平A、主动攻击、攻击型PP、治疗/护盾共享公共CD；大招不受该门槛限制，但释放后仍触发公共CD；各技能自己的CD仍独立。平A自身CD1.5秒。普通移动、冲刺、侧闪与架枪防御不受公共CD限制，但仍需精力和自己的CD就绪。
- 收招期间不能主动移动；收招结束即使公共CD尚未转好，也可通过基础AP慢速周旋恢复。物理击退不受主动移动限制。
- 角色血条下绿色条为精力，旁边显示剩余公共CD；详情显示精力数值和移速比例。玩家条件新增「自己精力≥80 / ≥50 / ≤30」，技能悬停说明列出精力消耗。
- 验证：`--resource-test` 检查末发计时、消耗、公共CD门槛、恢复、低精力速度和大招约束。

## 指挥官手动大招

- 战场上方有蓝1、蓝2头像，外环显示0–100%充能。存活时按模拟时间12秒充满，开局从0开始，满后保留，不受伤害或随机数影响。
- 满能后点击头像，整个战斗以当前播放速度的15%运行；鼠标方向控制投影后的真实预览，左键点击场内确认，右键/Esc或再点同一头像取消。点界外不消耗充能。
- 取消大招排队。充能满即可确认释放，不受精力或公共CD限制，接管当前动作；确认扣70精力，允许负数（30→−40），准备0.3秒、收招0.8秒。收招后按每秒12恢复，普通攻击/法术仍须满足精力要求；负精力保持55%普通移速，免费移动规则仍可执行。角色显示橙色负精力数字。取消瞄准不扣资源，赛后仍可使用。
- 蓝1「天穹贯穿」：长500、宽36像素直线光束，45真实伤害，穿敌人但被完整墙体截停，对墙造成45伤害；预览显示被墙截断后的长度。
- 蓝2「星火轰炸」：沿选定方向120/220/320像素三处落点，半径60，每枚22伤害；准备后飞行0.65秒、圆环满时落地，能越过墙体。边界处落点裁入场内，过近落点合并，避免在墙角重叠三炸。
- 暂时按蓝方两个成员固定分配大招，与AP/PP槽独立；红方不自动释放手动大招。用于测试指挥官干预，尚未做对称平衡。
- `--ultimate-test` 验证充能、取消/无效点击、慢放与倍率恢复、实际伤害、挡墙、炮击以及死亡/重开。`--ultimate-preview` / `--ultimate-barrage-preview` 捕获两种手动瞄准界面。

## 可破坏掩体

- 每块墙300HP；剩余≤200显示裂纹，≤100显示更密更深的裂纹，0HP崩碎并留下无碰撞碎石。
- 直射弹、霰弹、岩弹与激光被墙截停并按本次直击伤害扣墙血；打碎墙的攻击仍被墙挡住，后续攻击才能穿过。
- 抛射可越过掩体，爆炸范围与墙体相交时也对墙造成一次伤害。墙体无阵营，不受标记加成、荆棘持续伤害、治疗或角色撞击伤害。
- 同一模拟步中的墙体伤害统一结算，破坏后重建寻路并清空旧路径；重开恢复两堵300HP墙。机器人仍按原策略打敌人，不会自动把墙当作优先目标。
- `--wall-test` 验证血量阶段、弹道遮挡、破坏后射线/通行/导航、激光单次伤害、范围伤害及重开；`--wall-preview` / `--wall-broken-preview` 可查看裂纹和破碎状态。

## 圆环技能时序

抛射轰击改为 **单个半径64像素的圆形落点**，不再是三处散布，且不追踪移动目标。

1. 开始准备时锁定落点，显示完整的淡色伤害边界。
2. 准备0.25秒，圆环从顶部开始补完。
3. 抛射飞行0.65秒，圆环沿用同一个累计进度，不重置。
4. 总计0.9秒，圆环补满时爆炸，圈内身体重叠者受到18点伤害。
5. 满环爆炸反馈持续0.3秒，特效不造成重复伤害。

计时环与伤害圈使用同一半径；从上方覆盖圆形区域，不被墙阻挡。护盾、防御依然有效，无友伤。落点固定，提前走出半径（包含身体半径）可以躲避。其他技能仍有实弹、扇形霰弹、锁向蓄力光束等不同出招方式。

## 战斗节奏

- 两块掩体各20×112像素，位置中心不变，扩大绕行空间。
- 基础接敌/搜索速度126像素/秒；接敌后的侧移48像素/秒；常规避险仍为87像素/秒，侧闪240像素/秒（80像素距离不变）；绕侧/后撤速度提高20%，短冲刺从174提高到208.8像素/秒。侧移受射线、射程和碰撞约束，不引入随机数。

- 普通射击/霰弹/炮击收招0.45秒，重射/岩弹0.8秒；公共CD从生效/最后一发开始，与收招重叠。
- 霰弹准备0.25秒，落岩0.35秒；风系两发间隔0.22秒。长激光仍蓄力1.1秒、收招1秒。
- 公共CD或精力恢复时，基础行为做最多32像素的小幅侧移，面朝敌人，保持射程与视线；无安全位置则守住射位。
- 侧移没有无敌帧，逐帧让位于玩家AP、PP与真正的威胁规避。攻击型反应也遵守公共施法CD，避免连续插入高频射击。

## 周旋与闪避分工

- 平A弹速1300像素/秒，其余快招1400像素/秒，岩弹360、霰弹340；依然按真实弹道碰撞，不保证必中。
- 慢速周旋用于保持距离和射线，不自动追着普通弹道躲避。距离远、贴范围边缘或借掩体仍可能避开。
- 基础避险仅由长激光预警或圆形落点触发；有足够提前量才跑得出去。
- 配置侧闪后，对实际弹道或已锁定预警作出反应，约0.33秒移动80像素，冷却2.8秒；仅被瞄准不消耗闪避，没有无敌帧，不取消已经承诺的吟唱、开火或收招。
- `--defense-test` 验证三个距离满速跑动仍被平A命中、侧闪可躲慢岩弹，检查命中、冷却和长预警逃离。

## 小队配置

每个角色100HP，显示连续血条和数值；低血量条件改为≤50。相同属性与技能池，玩家通过条件优先级改变打法；无AP/PP点数。

- 玩家主动从上至下选择第一条可用规则，基础攻击/接敌/搜寻最后兜底。
- 战场事件触发相关反应，玩家PP先于基础步行避险。
- 规避按真实攻击形状、剩余时间和可达位置选择；已开始的吟唱、射击、收招不能免费取消。
- 底层不再自动等待收招反打；可由玩家配置“敌人正在收招”的攻击规则。
- 队友目标偏好、标记接强射、命中后协同追击、给队友护盾与治疗等配合继续保留。

固定场地边界，不再缩圈，60秒超时平局。界面距离改以米为单位（1米=80像素），只是长度标尺，不约束位置。

**暂不实现**召唤师部署、手动瞄准关键技能、3v3或宠物美术；先验证2v2的可读性和战术配置。

## 按配置换位与夹击

- 首个非空攻击技能决定稳定的理想交战距离（不随冷却切换）：霰弹125像素，炮击/烈焰爆破/激光240像素，其余攻击190像素。实际射程与命中规则不变。
- 一名队友正面维持距离，另一名争取约55度的攻击夹角，并优先避免挤在队友附近。失去队友后不再追求夹角。
- 接敌选点综合射线、理想距离、路程和队友间距；冷却期间位置明显不合适时主动贴近、撤远或绕侧。
- 有意义的换位保留目标0.8–2.4秒，按126像素/秒导航；玩家AP、事件PP和真实威胁避险可优先接管。普通小幅周旋仍为48像素/秒。
- `--position-test` 检查近远配置不同目标、夹角改善、目标持续和玩家规则优先。当前已关闭缩圈。

## 后坐力与受击位移

- 开火产生真实的短促后坐位移，重射、岩弹和光束后坐力更强；不取消当前动作。
- 弹丸沿入射方向击退，爆炸从圆心向外推。爆炸推力为炮击320、烈焰380像素/秒，施法者后坐140像素/秒；无障碍单次击退约90–110像素，连续爆炸累积速度上限650像素/秒；前0.22秒自主位移降至25%，不取消施法，不追加伤害。
- 光束持续0.55秒：首次命中扣血一次，同时向前和最近侧边推。仍接触光束则持续受力，离开或光束结束后惯性逐渐衰减；不额外造成连续伤害。
- 强制位移逐段检查墙、边界与角色碰撞，不穿墙、不越界；撞墙及场地边缘按法线反弹，保留72%速度，撞其他机器人则反弹（55%速度），并传递35%的法向速度推动对方，无额外伤害。`--impact-test` 验证方向、衰减、单次伤害和碰撞。

## 验证

```sh
Godot --headless --path . -- --arena-test
```

验证连续移动、单个固定落点、准备到飞行的进度连续、结算时间与实际半径、玩家PP优先，再跑风火队对九预设并交换出生侧的18场对局。报告：`reports/arena-validation.json`。
